# Obsolete Documentation — Archive

**Do not write to any file in this folder.**

These documents were written at various points in the project's history and have been
archived here. They are kept for reference only.

## Rules

- **The archived files are read-only.** Never edit, update, extend, or "fix" them. If
  you find something out of date, that is expected — leave it as it is. (Adding new
  files to this folder is fine — e.g. archiving further documents here.)
- **Not a source of truth.** The content may be inaccurate, incomplete, superseded, or
  simply describe things that were never built. It does not necessarily reflect the
  current reality of the workinabox system or organisation.

## How to use these files

Reading them is fine and often useful — they capture past intent, design discussions,
and historical context. But treat anything you read here as a *historical claim*, not
as fact. Before relying on any statement in these documents, verify it against the
actual code, infrastructure, or a current authoritative source.
